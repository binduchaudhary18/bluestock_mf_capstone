# Bluestock Mutual Fund Analytics Project

## Project Overview

This project presents an end-to-end Mutual Fund Analytics solution developed as part of the Bluestock Capstone Program. The objective was to analyze mutual fund performance, investor behavior, portfolio allocation, and risk characteristics using Python, SQL, SQLite, and Power BI.

The project covers the complete analytics lifecycle including data ingestion, data cleaning, exploratory data analysis, performance analytics, advanced risk analytics, dashboard development, and report generation.

---

## Objectives

* Analyze mutual fund performance
* Measure risk-adjusted returns
* Study investor demographics and behavior
* Perform SIP continuity analysis
* Build a fund recommendation engine
* Develop interactive Power BI dashboards
